# TP – DHCP, DNS et VPN

## Présentation

Projet pratique  consacré à l’installation et à la configuration de services réseau sous Windows Server.

## Objectifs

- Installer et préparer le rôle DHCP pour l’adressage automatique des postes clients.
- Installer et configurer le rôle DNS pour la résolution des noms.
- Installer les services d’accès distant et configurer le serveur VPN.
- Préparer la connexion VPN depuis un client Windows.

## Technologies et outils

- Windows Server
- DHCP (Dynamic Host Configuration Protocol)
- DNS (Domain Name System)
- Remote Access 
- Client Windows
